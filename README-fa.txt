ShahTunnel 5.5.3 — تعمیر مسیر اتصال کاربران Psiphon

این بسته، سورس کامل قابل آپلود در ریشهٔ مخزن GitHub است؛ نه اسکریپت تعمیر جداگانه.

اصلاحات:
- Xray Psiphon sidecar با ProtectHome=read-only اجرا می‌شود تا گواهی/کلید TLS داخل /root یا /home قابل خواندن باشد.
- نصب‌کنندهٔ GitHub پیش از راه‌اندازی مجدد Agent، سرویس قدیمی sidecar را فقط پس از تطبیق مالکیت ShahTunnel، نام سرویس و مسیر config همان پروفایل مهاجرت می‌دهد؛ از واحد قبلی نسخهٔ پشتیبان می‌گیرد و در صورت شکست restart آن را برمی‌گرداند. شروع بعدی پروفایل از منو نیز این کنترل را دارد.
- DNS هر پروفایل Tag یکتا دارد و DoH از SOCKS5/Psiphon عبور می‌کند؛ Cache حفظ شده و Queryهای موازی تکراری خاموش‌اند.
- بررسی آمادگی Agent، سرویس Psiphon مستقل و دست‌دهی SOCKS5 را می‌سنجد و با پیام‌های Journal سرویس اشتباه اشتباه نمی‌گیرد.

حفظ تنظیمات:
- فایل مبدأ X-UI و Inbound اصلی تغییر نمی‌کند.
- پورت ورودی اصلی کاربران، Client ID/UUID، Mappingها، SSH و Routeهای میزبان دست‌نخورده می‌مانند.
- هیچ بازگشت خودکاری به خروجی Direct انجام نمی‌شود؛ در صورت خرابی Psiphon مسیر کاربر fail-closed باقی می‌ماند.

روش استفاده از بسته GitHub:
1) ZIP را استخراج کنید.
2) محتویات پوشه/آرشیو را در ریشهٔ مخزن ShahNetLab/ShahTunnel قرار دهید و فایل‌های قدیمی را با نسخهٔ جدید جایگزین کنید.
3) پس از ثبت تغییرات روی شاخهٔ main، همان روش نصب آسان همیشگی را اجرا کنید؛ S1T-START.sh نسخهٔ سورس main را از GitHub دریافت و روی سرور build می‌کند.

نسخهٔ اجرایی برنامه و نصب‌کننده: 5.5.3
