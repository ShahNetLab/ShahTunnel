ShahTunnel 5.0.0 — تعمیر خودکار Tor Snowflake

این بسته یک اسکریپت تعمیر یک‌مرحله‌ای دارد که:
- گزینه Tor Snowflake را به منوی اضطراری برمی‌گرداند.
- Bridge پیش‌فرض Snowflake را خودکار استفاده می‌کند؛ ورود Bridge لازم نیست.
- رله‌های Tor با GeoIP آمریکا را در تمام موقعیت‌های مدار رد می‌کند.
- ورودی Agent، نام پروفایل و Mapping ذخیره‌شده را خودکار انتخاب می‌کند.
- با نصب‌کننده رسمی پروژه، باینری را روی VPS دوباره می‌سازد و نصب می‌کند.

روش اجرا:
1) فایل S1T-TOR-SNOWFLAKE-AUTO-FIX.sh را در ریشه مخزن GitHub ShahNetLab/ShahTunnel و شاخه main بارگذاری کنید.
2) روی VPS با دسترسی root اجرا کنید:
   bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-TOR-SNOWFLAKE-AUTO-FIX.sh)
3) بعد از نصب، از منوی اصلی T و سپس 1 را انتخاب کنید. Bridge، نام پروفایل، Agent و آدرس Mapping به‌صورت خودکار انتخاب می‌شوند.

نکته مهم: Snowflake از پراکسی‌های داوطلبِ چرخشی استفاده می‌کند و موقعیت فیزیکی آن‌ها قابل تضمین نیست. این اصلاح رله‌های Tor شناخته‌شده با کشور آمریکا را مسدود می‌کند و خروجی آمریکا یا خروجی تأییدنشده را رد می‌کند؛ اما تضمین جغرافیایی مطلق برای خود پراکسی داوطلب Snowflake ممکن نیست.

این بسته در محیط توسعه از نظر syntax و اعمال تغییرات روی fixture آزمایشی بررسی شده است؛ تست زنده روی VPS انجام نشده است.
