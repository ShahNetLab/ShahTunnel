ShahTunnel 5.5.12 - Config Schema Build Hotfix

این بسته رابط کاربری و تنظیمات تونل را جایگزین نمی‌کند. اسکریپت نصب همان نسخه 5.5.12 است، با دو اصلاح محدود در مرحله ساخت:

1) اگر سورس دریافت‌شده شامل S1T-CAPSULE/tor.go باشد ولی فیلدهای Tor در Config داخل main.go جا افتاده باشند، فقط فیلدهای اختیاریِ مفقود به همان struct اضافه می‌شوند. هیچ فیلد یا کد موجودی حذف یا بازنویسی نمی‌شود.
2) اگر فایل کمکی install-psiphon-hub-relay.sh در آرشیو بالادستی نباشد، نسخه همراه این بسته استفاده می‌شود. همین fallback برای دو helper دیگر نیز وجود دارد.

نصب:
- این ZIP را روی سرور آپلود و استخراج کنید.
- وارد پوشه ShahTunnel-5.5.12-ConfigSchema-Hotfix شوید.
- اجرا کنید: bash ./S1T-START.sh

مهم: نصب را از همین فایل محلی اجرا کنید؛ فرمان قدیمی bash <(curl .../S1T-START.sh) را اجرا نکنید، چون آن فرمان هنوز اسکریپت خام شاخه main گیت‌هاب را می‌گیرد و این اصلاح محلی را دور می‌زند.

این بسته سورس برنامه را از GitHub main می‌گیرد و روی همان نسخه موقت، پیش از build، سازگاری Config را اصلاح می‌کند. بنابراین برای ساخت به اینترنت سرور نیاز است. نسخه برنامه همچنان 5.5.12 است.

این اصلاح به‌تنهایی اتصال زنده Psiphon را اثبات نمی‌کند؛ فقط خطای build مشخص‌شده ناشی از نبود فیلدهای Tor در Config را هدف می‌گیرد. پورت کاربران 2083 و پورت‌های اختصاصی mapping در این patch دست‌کاری نمی‌شوند.
