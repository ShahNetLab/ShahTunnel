ShahTunnel 5.0.0 — اصلاح واقعی Emergency Tor / Snowflake

این بسته فایل کامل پروژه نیست؛ یک اسکریپت تعمیر یک‌مرحله‌ای است که سورس فعلی مخزن ShahNetLab/ShahTunnel را می‌گیرد، اصلاح می‌کند و با نصب‌کننده رسمی همان سورس اصلاح‌شده را build/install می‌کند.

اصلاحات:
- گزینه 1 به Tor Snowflake خودکار برمی‌گردد؛ Bridge دستی لازم نیست.
- پروفایل Agent فعال به‌صورت خودکار انتخاب می‌شود.
- نام پروفایل یکتا خودکار ساخته می‌شود.
- Mapping ذخیره‌شده/قابل‌استخراج از Agent استفاده می‌شود و prompt دستی ندارد.
- خطای قبلی رفع می‌شود: به‌جای ExcludeNodes که Bridge اسنوفلیک را هم مسدود می‌کرد، فقط خروجی‌های Tor آمریکا با ExcludeExitNodes {us} مسدود می‌شوند.
- بررسی خروجی عمومی Tor همچنان فعال است و خروجی آمریکا یا کشور تأییدنشده را نمی‌پذیرد.

نصب:
1) فایل S1T-TOR-SNOWFLAKE-AUTO-FIX.sh را در ریشه مخزن GitHub به‌جای نسخه قبلی همین فایل قرار دهید.
2) روی VPS با root فقط این دستور را اجرا کنید:
   bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-TOR-SNOWFLAKE-AUTO-FIX.sh)
3) پس از پایان موفق، منوی T و گزینه 1 (Snowflake) را انتخاب کنید. پس از آن ورودی Bridge/Agent/name/Mapping دستی پرسیده نمی‌شود.

مهم: این فیلتر خروجی‌های Tor با GeoIP آمریکا را ممنوع می‌کند. موقعیت فیزیکی پراکسی داوطلب Snowflake قابل تضمین/فیلتر جغرافیایی نیست؛ پس این روش تضمین نمی‌کند خود پراکسی داوطلب در آمریکا نباشد. تست نهایی شبکه باید روی VPS انجام شود.

اگر منوی سرور هنوز فقط WebTunnel را نشان می‌دهد، یعنی باینری قبلی اجرا شده یا اسکریپت تعمیر اجرا نشده است. اجرای عادی S1T-START به‌تنهایی این اصلاح را اعمال نمی‌کند؛ ابتدا اسکریپت بالا باید اجرا شود تا از سورس اصلاح‌شده build کند.
