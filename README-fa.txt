ShahTunnel 5.0.0 — بهینه‌سازی مسیر چندکاربره و اصلاح گزینهٔ ۹

نسخهٔ 5.0.0 یکپارچه‌سازی نسخه، مستندات و نصب‌کننده را انجام می‌دهد و یک ایراد مهم در رفتار گزینهٔ ۹ را اصلاح می‌کند.

اصلاحات اصلی:
- گزینهٔ ۹ چهار انتقال داخلی و Failover مستقل Direct/Psiphon/MASQUE فعال را برای Laneهای Agent↔Hub حفظ می‌کند.
- در گزینهٔ ۹، ترافیک TCP/DNS کاربران Xray نیز از Sidecar اختصاصی همان Agent و SOCKS5 سایفون عبور می‌کند؛ مسیر پیش‌فرض سرور یا SSH تغییر نمی‌کند.
- UDP/QUIC و ICMP از SOCKS5 سایفون پشتیبانی نمی‌شوند؛ UDP در Sidecar مسدود می‌شود تا به‌صورت ناخواسته از IP مستقیم سرور خارج نشود.
- گزینهٔ اختصاصی Psiphon / SOCKS5 نیز همچنان برای خروجی کاربران و Laneهای Agent از Psiphon استفاده می‌کند.
- زمان‌بندی Laneها همچنان از RTT معتبر، تعداد جریان‌های فعال، فشار صف و زمان انتظار نوشتن استفاده می‌کند.
- سرویس Psiphon مستقل از Restart سرویس Agent اجرا می‌شود؛ بنابراین Restart معمولی Agent تونل‌های گرم Psiphon را از بین نمی‌برد.
- هنگام ساخت Agent، Sidecar Xray و خروجی HTTPS واقعی Psiphon پیش از شروع Agent آماده و بررسی می‌شوند؛ Start مجدد نیز قبل از در دسترس قراردادن کاربران، خروجی واقعی و Sidecar همان پروفایل را کنترل می‌کند.
- عملیات Stop سرویس Agent، Sidecar اختصاصی Xray و Psiphon همان پروفایل را متوقف می‌کند؛ Start بعدی آن‌ها را دوباره راه‌اندازی می‌کند.
- نسخهٔ برنامه، نصب‌کننده، بنر ترمینال و مستندات به 5.0.0 ارتقا یافته‌اند.

نصب از مخزن:
bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-START.sh)

اعمال اصلاح روی Agent قدیمی با گزینهٔ ۹:
1. نسخهٔ 5.0.0 اصلاح‌شده را روی Agent نصب/جایگزین کنید.
2. از منوی ShahTunnel همان پروفایل Agent را Start/Restart کنید؛ Sidecar اختصاصی Psiphon پیش از شروع Agent ساخته و مسیر خروجی واقعی بررسی می‌شود. اگر Agent از قبل فعال بوده و Mapping قبلاً اعمال نشده باشد، فقط یک بار برای اعمال مسیر جدید Restart می‌شود.
3. IP را از دستگاه کلاینتی که به کانفیگ Xray وصل است بررسی کنید. اجرای `curl` روی خود VPS یا بررسی سرویس‌های نامرتبط، همچنان IP عادی سرور را نشان می‌دهد؛ Route پیش‌فرض سرور و SSH عمداً تغییر نمی‌کنند.

اگر اجرای قبلی نیمه‌کاره مانده و سرویس اختصاصی Xray/Psiphon از قبل وجود دارد، نسخهٔ 5.0.0 همان سرویس مدیریت‌شدهٔ متعلق به پروفایل را به‌روزرسانی می‌کند؛ سرویس ناشناس یا متعلق به پروفایل دیگر را دست‌کاری نمی‌کند. فایل‌های systemd را دستی حذف نکنید.

نکتهٔ ظرفیت: در گزینهٔ ۹ ترافیک کاربران این پروفایل از ظرفیت خروجی Psiphon عبور می‌کند؛ بنابراین Psiphon می‌تواند در بار هم‌زمان ۱۶ کاربر گلوگاه سرعت باشد. سرعت نهایی به CPU، RAM، ظرفیت شبکهٔ هر دو VPS، کیفیت مسیر و ظرفیت Relayهای Psiphon بستگی دارد. برای ارزیابی واقعی باید پس از نصب، بار و مصرف منابع هر دو سرور اندازه‌گیری شود.
