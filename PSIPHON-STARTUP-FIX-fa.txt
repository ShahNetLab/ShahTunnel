شاه‌تونل 4.0.5 — اصلاح خطای شروع Psiphon
==========================================

علت خطا
-------
در نسخهٔ قبلی، ویزارد Agent پیش از شروع systemd service می‌خواست SOCKS5 سایفون را به Xray متصل کند. چون ConsoleClient فرزند همان سرویس Agent است، پورت 127.0.0.1:PORT هنوز Listener نداشت و خطای connection refused رخ می‌داد.

اصلاح
-----
1) ابتدا سرویس همان پروفایل Agent فعال می‌شود.
2) آماده‌شدن تونل واقعی Psiphon بررسی می‌شود؛ صرفاً بازبودن پورت کافی نیست.
3) خروجی زندهٔ Psiphon از نظر IP و کشور کنترل می‌شود و آمریکا همچنان ممنوع است.
4) Sidecar مستقل Xray همان پروفایل ساخته و فعال می‌شود.
5) فقط سرویس همان Agent یک بار Restart می‌شود تا Mapping جدید را بارگذاری کند.
6) گزینه‌های Start و Restart نیز پروفایل ذخیره‌شده‌ای را که مرحلهٔ Xray آن در نسخهٔ قبلی نیمه‌کاره مانده، خودکار ترمیم می‌کنند.

ترمیم پروفایل فعلی
------------------
پس از نصب این بسته، منوی ShahTunnel را باز کنید و گزینهٔ 2 (Start a tunnel) را انتخاب کنید؛ سپس همان پروفایل Agent قبلی را انتخاب کنید. برای این پروفایل، Xray sidecar فقط در صورتی ایجاد می‌شود که هنوز نصب نشده باشد. سایر پروفایل‌ها دست‌نخورده می‌مانند.

توجه امنیتی
-----------
در متن خطای ارسالی، Token احراز هویت Hub دیده می‌شد. برای احتیاط، پس از اتمام تعمیر، Token مربوط به همان تونل را در Hub عوض و مقدار جدید را فقط در Agent متناظر ثبت کنید.
