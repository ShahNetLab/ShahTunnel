یادداشت نصب و اصلاحات ShahTunnel 1.6.3

نسخهٔ برنامه: 1.6.3
نسخهٔ ابزار ساخت پیشنهادی/دانلودی: Go 1.27.3
حداقل نسخهٔ Go سازگار با go.mod: 1.23.0

نصب‌کننده ابتدا Go سازگار موجود روی سرور را شناسایی می‌کند و در صورت سازگاری معماری، از آن استفاده می‌کند. اگر از پوشهٔ استخراج‌شده اجرا شود، سورس همان پوشه را به‌کار می‌گیرد؛ اجرای راه‌دور از دستور curl همچنان سورس شاخهٔ main را از GitHub دریافت می‌کند. اگر Go نصب نباشد یا نسخهٔ آن از 1.23.0 قدیمی‌تر باشد، آرشیو رسمی Go 1.27.3 را دریافت می‌کند.

SHA-256 آرشیوهای Linux amd64 و arm64 دقیقاً مطابق فهرست رسمی دانلود Go تنظیم شده است. آرشیو فقط پس از تطبیق کامل هش پذیرفته می‌شود. فایل‌های ناقص آینه‌ها از یکدیگر جدا هستند و ادامهٔ دانلود از میزبان دیگر روی فایل ناقص قبلی انجام نمی‌شود.

زمان اتصال و دانلود برای شبکه‌های کند افزایش یافته است. با این حال، اگر DNS یا دسترسی خروجی سرور به همهٔ میزبان‌ها قطع باشد، هیچ تغییر نرم‌افزاری نمی‌تواند دانلود را بدون دسترسی شبکه تضمین کند؛ در این وضعیت استفاده از Go سازگار نصب‌شده روی سرور می‌تواند مرحلهٔ دانلود ابزار Go را حذف کند.

نسخهٔ باینری، نصب‌کننده، اسکریپت بررسی و مستندات به 1.6.3 همگام شده‌اند. باینری پیشین پیش از جایگزینی پشتیبان‌گیری می‌شود و سرویس فعال در زمان نصب ری‌استارت نمی‌شود.
