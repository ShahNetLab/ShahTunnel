یادداشت نصب ShahTunnel 1.7.1
نسخه پیش‌فرض ابزار نصب: Go 1.26.10
حداقل نسخه go.mod: Go 1.26.0

اولویت انتخاب Go:
1) استفاده از Go موجود در PATH در نسخه 1.26.x یا 1.27.x و معماری سازگار؛ بدون دانلود و استخراج مجدد.
2) استفاده از toolchain تأییدشده‌ای که نصب‌کننده در /usr/local/lib/shah-tunnel/toolchains نگه داشته است.
3) اگر هیچ‌کدام موجود نباشند، بررسی HEAD آینه‌ها و دانلود Go 1.26.10 فقط پس از HTTP 200 و Content-Length معتبر، با تأیید SHA-256 رسمی.

آینه‌ها به ترتیب: go.dev/dl، dl.google.com/go، Aliyun، USTC، Tsinghua، Tencent، golang.google.cn/dl.
کد 403/404 یا پاسخ بدون Content-Length معتبر باعث عبور فوری به آینه بعدی می‌شود.

برای سازگاری با Go 1.26، وابستگی REALITY به revision 20260908062103-8cdf7bf9c7f0 pin شده است؛ go.mod آن revision حداقل Go 1.24.0 می‌خواهد. وابستگی golang.org/x/net v0.62.0 حداقل Go 1.26.0 می‌خواهد.

پیش از استفاده از آرشیو Go، SHA-256 ثابت از فهرست رسمی go.dev/dl بررسی می‌شود. دانلود یا build واقعی روی سرور مقصد پس از انتشار تغییرات در شاخه main باید اجرا و نتیجه آن بررسی شود.
