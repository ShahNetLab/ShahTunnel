Shah Tunnel 2.2.8 — یادداشت انتشار

این نسخه مسیرهای خارجی را در سطح هر پروفایل Agent اعمال می‌کند. Cloudflare WARP از Local Proxy رسمی روی 127.0.0.1:40000 به‌عنوان SOCKS5 استفاده می‌کند و به‌صورت پیش‌فرض Route سراسری VPS را تغییر نمی‌دهد.

پروتکل‌های قدیمی، SSH و پروفایل‌های دیگر از مسیرهای مستقل خود استفاده می‌کنند. اگر WARP از قبل در حالت Full-device و متصل باشد، برنامه پیش از تبدیل آن به Local Proxy تأیید تعاملی می‌خواهد. رد درخواست هیچ تنظیمی را تغییر نمی‌دهد.

توجه: این مسیر فقط اتصال Agent به Hub را از WARP عبور می‌دهد؛ خروجی اینترنت سرویس مقصد (از جمله Xray/VPN) باید جداگانه در همان برنامه به WARP SOCKS5 متصل شود.
