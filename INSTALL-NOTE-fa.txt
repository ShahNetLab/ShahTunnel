شاه‌تونل — نسخهٔ ۱.۷.۰

نصب سریع:
روی هر دو سرور با کاربر root این دستور را اجرا کنید:

bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-START.sh)

روی سرور ایران نقش Hub و روی سرور خارج نقش Agent را انتخاب کنید.

توجه: این دستور فایل نصب منتشرشده در شاخهٔ main مخزن را اجرا می‌کند. در بررسی ۴ نوامبر ۲۰۲۶، فایل آنلاین نسخهٔ 1.6.3 را اعلام می‌کند؛ برای نصب نسخهٔ 1.7.0 باید نصب‌کنندهٔ همین نسخه ابتدا در شاخهٔ main منتشر شود.

تنظیم تونل:
۱. روی هر دو سرور سیاست انتقال یکسانی انتخاب کنید.
۲. برای استفاده از پنج مسیر، گزینهٔ ۸ را انتخاب کنید.
۳. درگاه‌های کنترل پیش‌فرض عبارت‌اند از 9443/TCP، 9444/TCP، 9445/TCP و 9446/UDP.
۴. توکن، اثرانگشت گواهی، گذرواژهٔ Hysteria و گذرواژهٔ Salamander باید در دو سمت هماهنگ باشند.
۵. ابتدا Hub و سپس Agent را راه‌اندازی کنید.

محدودیت: گزینهٔ ۸ در صورت در دسترس نبودن UDP از مسیرهای TCP استفاده می‌کند؛ اما قطع کامل همهٔ مسیرها یا قطع بالادستی اینترنت با تعویض پروتکل قابل جبران نیست.
