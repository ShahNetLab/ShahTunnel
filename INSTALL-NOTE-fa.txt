نصب Shah Tunnel بدون دانلود Go

نسخه: 1.6.2

نصب‌کننده S1T-START.sh باینری آماده را بر اساس معماری سرور مستقیماً از پوشه S1T-CAPSULE مخزن GitHub دریافت می‌کند. فایل‌های موردنیاز:

- S1T-CAPSULE/shah-tunnel-linux-amd64
- S1T-CAPSULE/shah-tunnel-linux-arm64
- S1T-CAPSULE/BINARY-SHA256SUMS.txt

هیچ فایلی لازم نیست در بخش GitHub Releases بارگذاری شود. نصب‌کننده SHA-256، نسخه برنامه و معماری باینری را بررسی می‌کند و فقط پس از تأیید، آن را نصب می‌کند. روی سرور مقصد Go دانلود یا اجرا نمی‌شود و کامپایل محلی انجام نمی‌شود.

دستور نصب بدون تغییر باقی مانده است:

bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-START.sh)

برای انتشار نسخه جدید، باینری‌های هر دو معماری و S1T-START.sh باید در شاخه main به‌روزرسانی شوند. SHA-256های فعلی نیز در S1T-START.sh و BINARY-SHA256SUMS.txt ثبت شده‌اند.
