راهنمای انتشار Shah Tunnel 2.1.0 — باینری تک‌فایلی

ساختار لازم در شاخهٔ main مخزن GitHub:
- S1T-START.sh
- S1T-CAPSULE/main.go
- S1T-CAPSULE/main_test.go
- S1T-CAPSULE/ravanreverse
- S1T-CAPSULE/SHA256SUMS
- S1T-CAPSULE/README.txt

فایل اجرایی ravanreverse مستقیماً کنار main.go قرار می‌گیرد؛ نیازی به
زیرپوشهٔ bin یا پوشه‌های معماری نیست.

این باینری برای Linux amd64 (x86_64) کامپایل شده است. روی سرور arm64
قابل اجرا نیست؛ برای arm64 باید باینری جداگانه‌ای کامپایل و منتشر شود.

نصب مستقیم پس از push کردن فایل‌ها به شاخهٔ main:
  bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-START.sh)

نصب از پوشهٔ محلی مخزن:
  sudo bash S1T-START.sh

نصب‌کننده SHA-256 و نسخه/معماری باینری را پیش از نصب بررسی می‌کند.
روی VPS نیازی به نصب Go یا کامپایل برنامه نیست.
