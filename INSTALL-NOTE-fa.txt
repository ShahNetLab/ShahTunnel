اصلاح دانلود رسمی Go برای ShahTunnel 1.6.3

نسخه هدف: Go 1.27.3

نصب‌کننده آرشیو رسمی Go را برای معماری amd64 یا arm64 مستقیماً از go.dev دریافت می‌کند و در صورت اختلال، از دامنه‌های رسمی dl.google.com و storage.googleapis.com استفاده می‌کند. آینه‌های شخص ثالث استفاده نمی‌شوند. زمان اتصال ۳۰ ثانیه و زمان مجاز دانلود ۳۰ دقیقه است؛ تلاش‌های مجدد تا ۱۰ دقیقه ادامه دارند. فایل ناقص برای هر میزبان جداگانه نگهداری می‌شود و فقط از همان میزبان ادامه می‌یابد.

SHA-256 رسمی Go برای هر معماری پیش از استخراج بررسی می‌شود. سپس سورس ShahTunnel از مخزن GitHub دریافت و روی VPS ساخته می‌شود. هیچ باینری ShahTunnel داخل ZIP یا GitHub Releases لازم نیست. اگر DNS یا دسترسی HTTPS سرور به تمام میزبان‌های رسمی مسدود باشد، نصب بدون رفع مشکل شبکه ممکن نیست.
