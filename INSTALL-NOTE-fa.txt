نسخه اصلاح نصب ShahTunnel
==========================
نسخه ابزار Go در این بسته: 1.26.1

اصلاحات:
- GO_VERSION روی 1.26.1 تنظیم شده است.
- SHA-256 رسمی Go 1.26.1 برای Linux amd64 و arm64 تنظیم شده است.
- آینه‌های جایگزین بیشتر به ترتیب دانلود افزوده شده‌اند.
- برای تلاش‌های دانلود، زمان انتظار محدود گذاشته شده است.
- خطای واقعی curl برای تشخیص DNS، TLS، HTTP و timeout نمایش داده می‌شود.
- اعتبارسنجی SHA-256 حذف نشده است.

نکته مهم:
اگر دستور زیر را اجرا کنید، اسکریپتی که در حال حاضر روی GitHub قرار دارد دریافت می‌شود؛
این کار به‌تنهایی فایل داخل این ZIP را روی GitHub جایگزین نمی‌کند:
  bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-START.sh)

برای استفاده از اصلاحات، فایل S1T-START.sh این بسته را در شاخه main مخزن جایگزین کنید،
یا همین فایل را مستقیماً به VPS منتقل و از مسیر محلی اجرا کنید.

اگر همه منابع دانلود از شبکه VPS قابل دسترسی نباشند، نصب همچنان به رفع دسترسی DNS/HTTPS نیاز دارد.
