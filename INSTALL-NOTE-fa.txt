اصلاح دانلود رسمی Go برای ShahTunnel 1.6.3

نسخه هدف: Go 1.27.3

نصب‌کننده آرشیو رسمی Go را برای معماری amd64 یا arm64 دریافت می‌کند. ترتیب میزبان‌ها:
۱) dl.google.com/go (میزبان مستقیم فایل رسمی Go)
۲) storage.googleapis.com/golang
۳) go.dev/dl

اگر DNS دامنه‌ای در VPS در دسترس نباشد، نصب‌کننده بدون تکرار بی‌فایدهٔ همان خطا به میزبان رسمی بعدی می‌رود. در ترمینال SSH، curl درصد واقعی دانلود و سرعت را نشان می‌دهد؛ نوار متحرک قبلی فقط نشانگر فعالیت بود، نه درصد دانلود.

زمان اتصال ۲۵ ثانیه و حداکثر زمان دانلود ۳۰ دقیقه است؛ دانلود ناقص برای هر میزبان جداگانه نگهداری می‌شود و فقط از همان میزبان ادامه می‌یابد. از آینه‌های شخص ثالث استفاده نمی‌شود.

SHA-256 رسمی Go برای amd64 و arm64 پیش از استخراج بررسی می‌شود. سپس سورس ShahTunnel از شاخه main مخزن GitHub دریافت و روی VPS ساخته می‌شود. هیچ باینری ShahTunnel داخل ZIP یا GitHub Releases لازم نیست.

اگر DNS هر سه میزبان رسمی یا دسترسی HTTPS خروجی سرور مسدود باشد، ابتدا باید مشکل DNS/شبکه VPS برطرف شود؛ اسکریپت نمی‌تواند اتصال اینترنتی را از داخل خودش ایجاد کند.
