اصلاح دانلود Go برای ShahTunnel

نسخه هدف: Go 1.26.1

نصب‌کننده دانلود Go را بین منابع مختلف ادامه می‌دهد و در صورت پشتیبانی سرور از HTTP Range، دانلود ناقص را از همان نقطه ادامه می‌دهد. زمان کل دانلود محدود به 45 ثانیه نیست؛ اتصال بسیار کند پس از 180 ثانیه بدون پیشرفت متوقف می‌شود. بررسی SHA-256 رسمی برای معماری amd64 و arm64 همچنان اجباری است.

برای اجرای دستور از مخزن، فایل S1T-START.sh باید در مخزن GitHub جایگزین شود؛ دانلود ZIP به‌تنهایی فایل مخزن را تغییر نمی‌دهد.
