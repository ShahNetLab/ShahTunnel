راهنمای نصب مستقیم ShahTunnel 1.6.3

این بسته فقط سورس، نصب‌کننده و تنظیمات ساخت خودکار را دارد؛ هیچ فایل اجرایی/binary در ZIP قرار داده نشده است.

مراحل انتشار:
1) در مخزن ShahNetLab/ShahTunnel شاخه release-1.6.3 بسازید. از شاخه main استفاده نکنید تا نسخه جدیدتر main بازنویسی نشود.
2) تمام محتوای این ZIP را در ریشه شاخه release-1.6.3 بارگذاری و commit کنید.
3) در GitHub، بخش Settings > Actions > General، مجوز Workflow permissions را روی Read and write permissions قرار دهید.
4) از Actions اجرای Build and publish ShahTunnel 1.6.3 binaries را بررسی کنید. پس از موفقیت، باینری‌های دو معماری و فایل‌های .sha256 در dist/ ساخته و به همان شاخه commit می‌شوند.
5) روی VPS دستور زیر را اجرا کنید:

bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/release-1.6.3/S1T-START.sh)

نصب‌کننده باینری مناسب معماری را هنگام نصب از GitHub دریافت می‌کند، هش و نسخه/معماری را بررسی می‌کند و Go لازم نیست روی VPS نصب باشد.

نکته: تا قبل از موفقیت GitHub Actions، فایل‌های dist در شاخه منتشر نشده‌اند و نصب‌کننده نمی‌تواند باینری را دریافت کند. اگر Actions مجوز نوشتن به شاخه نداشته باشد، انتشار dist انجام نمی‌شود. در آن صورت تنظیم Workflow permissions را بررسی کنید.

برای مسیر جایگزین ساخت محلی، نصب Go سازگار 1.23.0 یا بالاتر لازم است. دانلود خودکار Go از آینه‌ها پیش‌فرض خاموش است و با SHAHTUNNEL_ALLOW_GO_DOWNLOAD=1 فعال می‌شود.
