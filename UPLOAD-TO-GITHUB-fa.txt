شاه‌تونل 4.0.0 — راهنمای جایگزینی سورس در GitHub

این ZIP یک بستهٔ کامل Repository Root است؛ فایل‌های پروژه از همان ریشهٔ مخزن شروع می‌شوند و داخل یک پوشهٔ اضافه قرار نگرفته‌اند.

اصلاح این بسته: خطای ساخت سرویس VPN Gate/OpenVPN برطرف شده است. مقدار `WorkingDirectory` اکنون بدون کوتیشن و فقط با مسیر مطلق نوشته می‌شود؛ برای جلوگیری از برگشت ایراد، تست رگرسیون به مجموعهٔ تست‌ها اضافه شده است.

1) مخزن ShahNetLab/ShahTunnel را روی شاخهٔ main باز کنید.
2) ZIP را روی رایانه استخراج کنید.
3) فایل‌ها و پوشه‌های استخراج‌شده را در ریشهٔ مخزن جایگزین نسخهٔ فعلی کنید؛ پوشهٔ S1T-CAPSULE و docs را هم حفظ کنید.
4) تغییرات را در شاخهٔ main ثبت و Push کنید. خود فایل ZIP را به‌عنوان یک فایل داخل مخزن آپلود نکنید.

- OpenVPN رایگان از VPN Gate به‌صورت خودکار راه‌اندازی می‌شود: ShahTunnel فهرست رسمی سرورها را می‌گیرد، کشور را از منو انتخاب می‌کند یا بهترین سرور در دسترس را خودکار انتخاب می‌کند، کانفیگ TCP را دریافت می‌کند و اعتبارنامهٔ عمومی vpn/vpn را در پوشهٔ خصوصی همان پروفایل می‌نویسد. نیازی به آپلود فایل یا واردکردن مسیر نیست. پس از اتصال، IP خروجی از مسیر علامت‌گذاری‌شده بررسی می‌شود و در صورت خطا سرور بعدی امتحان می‌شود.

پس از انتشار سورس، روی Agent خارج از ایران نصب/ارتقا را اجرا کنید:

bash <(curl -fsSL https://raw.githubusercontent.com/ShahNetLab/ShahTunnel/main/S1T-START.sh)

در OpenVPN، ویزارد بدون ورودی دستی، کشورها و سرورهای TCP رایگان VPN Gate را فهرست می‌کند، سرورهای در دسترس را امتحان می‌کند و فقط پس از تأیید IP خروجی همان پروفایل را می‌پذیرد. پروفایل‌های قدیمی دست‌نخورده می‌مانند.

اگر پروفایل Agent قدیمی از مسیر خروجی حذف‌شده استفاده می‌کرد، نسخهٔ جدید آن را به Direct تبدیل نمی‌کند و شروع آن را رد می‌کند. فقط همان پروفایل Agent را دوباره با MASQUE، Psiphon یا OpenVPN بسازید؛ پروفایل Hub ایران را حذف یا تغییر ندهید.

نکات مهم:
- این عملیات X-UI، کانفیگ اصلی Xray، SSH و Route پیش‌فرض سیستم را تغییر نمی‌دهد.
- ترافیک TCP و DNS از Psiphon عبور می‌کند. UDP/QUIC و ICMP روی مسیر SOCKS-only مسدود/غیرفعال‌اند تا UDP به‌صورت مستقیم نشت نکند.
- هنگام ساخت Agent جدید، Sidecar قبل از شروع Agent آماده می‌شود؛ هیچ سرویس SSH یا X-UI نباید restart شود.
VPN Gate از رله‌های داوطلبانه استفاده می‌کند؛ سرور و IP خروجی را خود VPN Gate فراهم می‌کند و اعتبارنامهٔ عمومی vpn/vpn به‌صورت خودکار تنظیم می‌شود. برای داده‌های حساس مناسب نیست.
- بعد از اتصال VPN روی دستگاه کاربر، IP را بررسی کنید. باید با IP خروجی SOCKS5 سایفون برابر باشد، نه IP عمومی Agent.
- در نسخه 4.0.0 اندازه‌گیری RTT داخلی هر ۵ ثانیه تازه می‌شود و نمونه‌های قدیمی‌تر از ۱۵ ثانیه از رتبه‌بندی کنار می‌روند. روی Agent دارای حداقل ۳ GiB RAM، پنجرهٔ کانال SSH سایفون از مقدار پیش‌فرض ۴ به ۱۶ (۵۱۲ KiB) افزایش می‌یابد؛ روی میزبان کم‌حافظه مقدار ۴ حفظ می‌شود. محدودیت‌های Meek/Relay و Threadهای CPU نیز متناسب با RAM/CPU تنظیم می‌شوند و اندازهٔ پیش‌فرض Tunnel Pool تغییر نمی‌کند. این تغییرها توان TCP و انتخاب Lane را بهینه می‌کنند، اما کاهش پینگ فیزیکی یا زمان اتصال انتهابه‌انتهای برنامه را تضمین نمی‌کنند. مسیر SOCKS5 فقط TCP/DNS دارد؛ UDP/QUIC و ICMP پشتیبانی نمی‌شوند.
